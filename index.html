04

공문 업로드 필수

작성한 IP 등록 공문을 첨부해 주세요. 첨부 후 연동 테스트를 신청할 수 있습니다.

공문 제출 전 확인해 주세요
  • 제출하는 공문에는 회사 직인이 반드시 날인되어 있어야 합니다.
  • API 호출 서버의 IP는 공인 IP로 기재해 주세요. 다음 IP 대역은 등록할 수 없습니다.
    사용 불가능한 IP 대역
    • 사설 IP: 10.0.0.0 ~ 10.255.255.255
    • 사설 IP: 172.16.0.0 ~ 172.31.255.255
    • 사설 IP: 192.168.0.0 ~ 192.168.255.255
    • 자기 컴퓨터 주소: 127.0.0.0 ~ 127.255.255.255
  • 요청하신 IP의 보험개발원 방화벽 정책 적용에는 2~3일이 소요됩니다. 승인되는 대로 SMS로 안내해 드립니다.
